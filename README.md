# 🌴 Aksari Resort Website

## 🧾 Overview
A luxury single-resort website designed to showcase a premium coastal stay experience.  
Focused on immersive visuals and call-based booking to drive direct conversions.


## 📖 Description
This project is a modern, editorial-style resort website inspired by high-end travel experiences.  
It emphasizes smooth animations, parallax effects, and minimal UI for a premium feel.  
The design ensures seamless navigation, responsiveness, and strong visual storytelling.

---

## ✨ Features
- 📱 Fully Responsive Design  
- 🎞️ Smooth Animations (fade, slide, parallax)  
- 🧭 Navigation to Section (smooth scroll)  
- 🖱️ Hover Effects (cards, images, buttons)  
- ⏳ Countdown Timer
